# mmdx components

Styled Mermaid as framework-agnostic web components. Every story here uses the real components from `src/`, with the
shipped examples (`examples/`) and themes (`themes/`).

## Elements

- **`<mmdx-viewer>`** (`mmdx/viewer`): read-only diagram with pan and zoom, layers, pen, code view, history, export, fullscreen and fallbacks.
- **`<mmdx-editor>`** (`mmdx/editor`): visual editor with the Mermaid code and layout metadata side by side, and the diagram's history; every feature can be switched off.
- **`<mmdx-diff>`** (`mmdx/diff`): how a diagram changed between two versions, and its version history — the view behind the History of the editor and the viewer.
- **`<mmdx-theme-editor>`** (`mmdx/theme-editor`): edits themes (palette, fonts, item and page presets) with live previews.
- **`<mmdx-studio>`** (`mmdx/studio`): the standalone app, with editor, examples (each with a six-version history), share, export, theme editor and Plain Mermaid.
- **Markdown** (`mmdx/markdown`): build-time HTML with server-rendered SVG, and the run-time upgrade of Mermaid code blocks.

## UI

The chrome the elements are built from, shown on their own with mock APIs: the code editor, the style toolbar, the
page toolbar, item previews and presets, icons, shapes, the logo, design tokens, dialogs and toasts.

## Core

`renderToSvg()` (DOM-free rendering for SSR and exports) and the semantic diagram diff (`renderDiffToSvg()`, `diffReport()` for CI).

## Conventions

- Every element takes `ui="light|dark|auto"` for its chrome; diagrams take any theme id (`theme`).
- Events are `mmdx-*` `CustomEvent`s; the stories log them to the browser console.
- Documents and themes are in memory here: nothing is saved.
